# Alex Brain — candidate profile for Cognition

Single-page, mobile-friendly profile: new-logo case studies (Barclays, Sandvik, Securitas), professional summary and timeline, leadership approach, and personal bio.

- `npm install` then `npm run dev` to develop, `npm run build` to build into `dist/`.
- Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml` (Settings → Pages → Source: GitHub Actions).
- Content lives in `index.html`; styles in `src/style.css`; images, logos and the CV PDF in `public/`.
